# Campus La Mar — Frontend

Parte frontend del sistema de gestión y reservas para el centro de formación Campus La Mar.

El proyecto se desarrolla como parte de las prácticas del módulo **Diseño de Interfaces Web (DIW)** en el 2.º curso de DAW (IES La Mar).

## Objetivos

* Desarrollo de la interfaz para la gestión de cursos, matrículas, aulas y horarios.
* Maquetación semántica con HTML5 y CSS3.
* Diseño responsivo adaptado a móviles, tablets y escritorio[cite: 6, 10].
* Cumplimiento de pautas básicas de accesibilidad (WCAG) y usabilidad en la navegación.
